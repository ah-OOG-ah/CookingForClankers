# Testing Plan

## Scope

### All Required Features

- **Homepage**: Includes a welcome message and featured recipe.
- **Recipe Cards**: Interactive recipe cards with thumbnails, descriptions,
  and like buttons.
- **Search Functionality**: Real-time search for recipes by name.
- **Recipe Detail Pages**: Each page displays ingredients, instructions, and
  additional details for the corresponding recipe.
- **Favorites Page**: A dedicated page for saved recipes using persistent
  local storage.
- **Visual Design** Appealing, functional, no seizure-induction elements.
  Consistent color schemes, typography, and smooth animations. Wayfinding
  elements throughout the website.

### Completed Optional Features

- Recipe sharing links
- Ingredient multiplication
- Theme switcher
- User ratings and reviews
- Recipe of the day feature

## Target Audience

Students at Franciscan University of Steubenville

## Devices and Browsers Tested

50% will test with their personal laptops running Chrome, Firefox, or Safari.

50% will test with their cell phones.

The device and browser will be recorded for each subject.

## Task Scenarios

1. **Recipe of the Day**
   - **Goal**: Test usability of the Recipe of the Day feature.
   - **Starting conditions**: Start on the homepage.
   - **Instructions**: Find the details for the Recipe of the Day.
   - **Completion condition**: On the Recipe Details page for the recipe of the
     day.

2. **Search for "Lemon Cheesecake Bars"**
   - **Goal**: Test search functionality.
   - **Starting conditions**: Start on the homepage.
   - **Instructions**: Use the search bar.
   - **Completion condition**: On the Recipe Details page for Lemon Cheesecake
     Bars.

3. **Like and Unlike Recipes**
   - **Goal**: Test usability of the Favorites functionality.
   - **Starting conditions**: Start on the homepage.
   - **Instructions**: Add three recipes from the Index to Favorites, then
     remove them from the Favorites page.
   - **Completion condition**: The three recipes you just favorited are no
     longer favorited.

4. **Recipe Multiplier**
   - **Goal**: Test usability of the Ingredient Multiplier.
   - **Starting conditions**: Start on the details page for any recipe.
   - **Instructions**: Quadruple the ingredients of your recipe.
   - **Completion condition**: The ingredient quantities are quadrupled.

5. **Scathing Review**
   - **Goal**: Test usability of the Review feature.
   - **Starting conditions**: Start on the details page for any recipe.
   - **Instructions**: Leave a scathing review on this recipe with 2 stars and a
     nasty comment.
   - **Completion condition**: The review is added to the reviews card.

## Metrics to Collect

Functional (Quantitative)

- Clicks/task
- Time/task

Design (Qualitative)

- What parts, if any, confused you?
- Were any parts misleading or difficult to distinguish/read?
